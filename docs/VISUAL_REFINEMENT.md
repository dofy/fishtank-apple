# 2026-10-21 像素美术细化

用户指出当前视觉与 PC FISH 的精致程度差距明显。本轮针对素材密度、材质表达和界面层次调整，保持现有玩法与彩蛋；不以更粗的描边代替像素细节。

## 设计依据

参考 [PC FISH 官方商店](https://store.steampowered.com/app/4842670/PC_FISH_Taskbar_Aquarium/) 与官方装饰包公开画面。沿用原创素材，关注小尺寸可读的轮廓、区分材质的色阶与安静的桌面陪伴感。

- 基础色：深海底色 `#142F40`、卡片 `#224555`、内嵌玻璃 `#173644`、钢蓝外壳 `#7797A0`、沙金 `#F0C66E`、奶白 `#F1EED4`。
- 字体：继续使用 Fusion Pixel 12px；不通过缩小文字堆叠内容。
- 布局：保留统一卡片高度、单行操作、40pt 按钮与固定的名称区。将图像放入内嵌展示区，阅读顺序为图像、名称、属性、状态、操作。
- 层次：1pt 外轮廓、内侧细线、上缘反光与底部阴影；保留阶梯圆角、透明水体，避免模糊滤镜。

## 素材变化

- 鱼类画布 64×48，显示尺寸维持 32×24 场景单位，继续 nearest 采样。保留三帧游动、五品阶配色与河豚四级膨胀。
- 鱼体补充鳍条、鳃线、腹部、少量鳞片和眼睛高光。蝶鱼、刺尾鱼、菱形鱼、细长鱼的轮廓分别处理。
- 石材、植物、贝壳、沉木、宝箱、金属与城堡分别使用材质色阶。海草使用交替叶片，礁石加入切面和苔藓，贝壳补珍珠层次，珊瑚补分叉，宝箱补木纹和铆钉，城堡补砖缝。
- 玻璃边框补接合点和短反光，底砂增加上下层次及少量卵石。灯光保留可见灯泡与电鳗变色联动。
- 界面图标统一 16×16；鱼名旁不重新增加锁图标，锁定状态继续由底部按钮表示。

## 范围

只修改渲染与界面。鱼种 ID、养成数值、存档格式、装饰解锁、音频、跨屏拖动、右下角召回、Dock 切换行为保持原有实现。
