# Web / Apple 功能对照（2026-10-21）

对照范围：本机 `fishtank` Web 工作区（HEAD `d704acc`）与 `fishtank-apple` 当前源码；不是线上部署状态核验。

## 已有的主要功能

- 29 鱼种、五品阶、21 组繁育星级配方、10 条材料合成、成长与离线结算、经验拆分、爱心与初始鱼冷却、等级 / 展示位扩容。
- 锁定保护、推荐配对、自动选材及筛选、永久鱼种 / 品阶图鉴。
- 18 件装饰、14 项成就与勋章展示、三首音乐、17 种音效、昼夜 / 自动、串灯流光与频率。
- 点鱼受惊、河豚膨胀、追逐食物与浮游生物、同种鱼临时结群、海马依海草休息、小鱼穿拱门。
- 隐藏彩蛋：触发条件、持续时间、受影响范围与冷却均与网页版一致；具体参数见 `Sources/Core/AquariumEcology.swift` 与 `Tests/EcologyTests.swift`，文档不再复述。
- 原生存档自动保存、备份、恢复、导出及显式导入 Web v1 JSON。没有自动读取浏览器存档或云同步。

## 本轮补齐 / 修正

- 展示高亮仅用于鱼群、装饰、勋章的展示管理；繁育 / 合成仅本次选中的材料使用黄色高亮，在缸状态只保留“展示中”角标。

- iPad 独立应用布局去除 Mac 外窗框，预览圆角透明合成；去除标题栏，横屏左右分区、竖屏上下布局，内容内“全屏预览”进入沉浸鱼缸；预览无按钮，单击水面投喂或点鱼互动，双击弹像素风退出确认，取消继续观赏、确认返回原手册状态；水域随视口扩展，横竖屏铺满且鱼与造景保持比例。
- macOS 悬浮鱼缸仅在主动隐藏时暂停；唤醒、会话恢复和显示配置变化后重新绑定原场景，保留节点、透明度和游戏状态。恢复测试覆盖呈现场景丢失及重复恢复；用户报告的偶发灰屏尚未原样复现。
- 勋章整卡挂上 / 取下，采用与鱼群、装饰相同的展示高亮；收藏鱼种为静态图鉴条目，用浅蓝灰平面底色和细像素边框区分操作卡片，保留品阶进度及现有 / 展示数量。

- 鱼群 / 繁育 / 合成与装饰采用整卡点击；锁定、放生、翻转为独立按钮。顶部共享爱心改为五颗实心 / 空心图标；Mac 状态栏显示总鱼数与可用繁育爱心数，菜单区分成长、冷却与可配对。
- 共用信息栏固定在滚动区域上方；标签切换重建内容滚动位置。鱼群页补齐五种排序与升降序，鱼群 / 繁育 / 合成及图鉴中的在缸鱼种增加展示标记，个体剩余繁育次数改为实心 / 空心像素爱心。

- Web `src/render/realistic.ts` 的两组背景鱼群此前缺失：7 条楔形银色小鱼、6 条沿弧线缓游转向的圆身鱼。现以像素剪影加入原生场景；它们是背景，不计背包、展示位，也不消耗养成随机数。
- 底砂基础高度由 15 提到 24 场景单位，保留起伏与卵石。
- 海底造景取消固定 y=13；按物件宽度下方最低沙面略微嵌入，拖动时重新计算落点。同步更新海马休息、穿拱门的目标高度，以及鱼和食物的底部边界。

## 仍未等量迁移的内容

| Web 功能 | 当前原生情况 |
| --- | --- |
| 图鉴物种详情、放大观察、选择同种个体并管理 | 有鱼种 / 品阶进度和现有数量，缺独立详情与观察页 |
| 繁育手动切换排序 | 鱼群页已有星级、品阶、繁育次数、展示状态、获得时间排序及升降序；繁育页仍按可繁育优先、星级和品阶排序 |
| 繁育 / 合成的分阶段仪式动画、揭晓后观察场景 | 已有结果弹窗和音效，缺完整演出流程 |
| 中英文切换 | 原生界面目前为中文 |
| 完整帮助弹窗、独立更新日志、网页全部快捷键 | 有小贴士与部分原生快捷键，未逐项迁移 |
| 远景礁脊、海扇、多层水下景深及连续光照 / 沙面光池 | 已有透明水、夜灯、背景小鱼、造景与底砂，远景礁脊等仍未补齐 |

网页的 LCD / 其他皮肤和浏览器沉浸模式没有照搬：原生按用户要求统一彩色像素风，并用独立桌面鱼缸承担陪伴展示。云同步也不应算作已经具备的能力。

## 验证入口

- `Tests/EcologyTests.swift`：彩蛋触发窗口、日夜灯色、物种保护规则及其他生态行为。
- `Tests/BackdropTests.swift`：两组背景鱼群的数量、运动 / 转向、沙面高度与造景接触。
- `tools/verify-release.sh`：核心测试、Mac 双架构与 iPad 无签名归档。
