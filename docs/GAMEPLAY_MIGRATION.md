| 亲代限制 | 两条不同鱼、成年、有次数、有爱心；仅初始鱼繁育后冷却 3 分钟；其他亲代扣次数、不新增冷却 |

| 合成经验 | 出生不发经验，成年时结算全额；不消耗爱心 |

| 保护 | 锁定阻止放生和所有合成选材；仍可展示与繁育；初始鱼不可放生或合成 |
| 图鉴 | 永久鱼种和品阶历史；放生、合成不清除；显示现有数量与 137 个基础品阶外观进度 |
| 本地进度 | 原子写入；随机状态随存档保留；操作先成功写盘再发布结果，写盘失败不消耗材料或爱心 |

Mac 菜单栏增加“养成 / 繁育 / 合成 / 图鉴”入口，打开操作手册；桌面鱼缸仍保持无边框、置顶、半透明，不把操作表单铺在桌面上。iPad 使用同一套操作界面。

彩色像素渲染扩展至鱼、水母、海马、鳗鱼、海蛇、鳐、海龟体型；不同鱼种使用原始颜色、花纹与形态参数，品阶改变色相。贴图在固定 32×24 网格生成并用 nearest 过滤，鱼缸水体透明度不影响鱼体。此轮美术仍为程序像素图，不等同于逐鱼种手绘动画资源。

## 存档兼容

沿用容器内 `Application Support/FishtankApplePrototype/aquarium-v1.json` 的路径，内容升级为 schema 2。路径不改是为了自动找到此前原型，不代表仍使用 schema 1。

首次读取 schema 1 时先保留 `.prototype-backup` 原文件；三种占位配色映射到原版初始鱼，保留个体 UUID、心数和成熟截止时间，不额外赠送经验。不覆盖旧备份。无法读取或校验失败时保留原文件并阻止写入和会消耗资源的操作。此路径不读取网页 localStorage。

后续 0.3.0 已迁移 18 件装饰、音频和 14 项成就勋章，并升级到 schema 3，见 PIXEL_DESIGN.md。0.4.0 又加入网页版 v1 JSON 显式导入、原生导出/恢复与观赏生态彩蛋，当前证据见 RELEASE_CHECKLIST.md。未加入云同步。

## 五星重铸与隐藏物种

规则对照当前网页项目的 `src/core/reforge.ts`；源仓库只读。合成页分为「普通合成」和「五星重铸」。

- 重铸永久消耗 3 条不同的五星生物，要求成年、繁育次数耗尽、未锁定、未展示。确认前可自动选材：1 条最高品阶加 2 条低品阶；不会解除锁定或自动收回展示个体。
- 产出 1 条五星幼体，继承材料最高品阶，重新抽取繁育次数，20 分钟成年。不耗爱心，出生不发经验，成熟只结算一次全额经验。
- 常规抽取为 80% 普通五星、20% 隐藏生物，三种隐藏等概率。连续 9 次没有发现新的隐藏物种后，下一次必得尚未发现的一种；重复隐藏不重置计数。集齐后停用保底，保持 20% 隐藏概率。
- 幽灯鮟鱇、琉璃海天使和星轮鹦鹉螺只进入重铸产出池，不进入普通繁育或合成产出池。隐藏亲代也不会在普通繁育中产出隐藏物种。
- 隐藏图鉴条目在首次发现前完全不显示；未发现的普通物种显示黑色剪影和 `???`。普通收集仍按 29 种、137 个基础外观计算，原有 14 枚勋章的条件不变。
- 新增「秘海初逢」与「秘海三重奏」两枚永久勋章，分别奖励首次获得和集齐三种隐藏物种；放生或消耗后仍保留记录。
- 三款隐藏物种图标沿用现有像素鱼缸设计。所有物种的图标在发现前隐藏，发现后永久可选。已有图标偏好和授权书签继续保留。

沿用 schema 3，新增整数 `reforgeMisses`（0–9）；缺失字段的旧原生/网页存档默认 0，非法类型或越界拒绝导入。既有个体、成长时间、音频、装饰和接入配置不迁移或重置。重铸继续使用先写盘后发布的事务流程，写入失败不消耗材料、随机状态或保底计数。

`Tests/ReforgeTests.swift` 对照 72 组独立网页版样本，并覆盖概率边界、重复隐藏、新发现保底、普通产出隔离、材料保护、成年结算、持久化和旧存档迁移。`Tests/AppIconCatalogTests.swift` 覆盖未发现图标隐藏、重铸后出现及移除个体后保留。
