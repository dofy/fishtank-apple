# Fishtank 隐私说明

本应用离线运行，无账号、广告、分析 SDK、联网接口或开发者服务器。不收集或上传个人信息。

鱼、成长时间、图鉴、装饰、成就、音量和灯光保存在设备本地。Mac 的窗口位置、大小、置顶、透明度和提醒开关也保存在本机。

导入与导出只访问你在系统文件选择器中选定的 JSON 文件。导出的 JSON 包含游戏进度；从网页版导入后，原始快照也保留在本地备份内，以保全旧昵称和兼容元数据。文件的后续保存和分享由你决定。删除应用前请导出，系统卸载可能移除本机数据。

本地通知仅在你主动授权后启用，用于成年、初始鱼冷却和爱心回满提醒。可在游戏或系统设置中关闭。通知由操作系统调度，不依赖服务器。

`PrivacyInfo.xcprivacy` 声明不跟踪、不收集数据。UserDefaults 用于本应用偏好（CA92.1）；文件元数据用于本应用存档轮换（C617.1）及用户选择文件的大小检查（3B52.1）。声明依据 [Apple 官方 required-reason API 文档](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitypereasons)，2026-10-20 核对。

公开发布前，发布者应提供可用的支持联系方式，并将本说明放在自己控制的公开页面上；此仓库未自动发布任何页面。
