# Chunky pixel artwork

Original artwork generated using the official built-in imagegen tool. The second six-sample style was approved before the full set. No PC FISH assets are copied or bundled.

Sources are in `Sources/Resources/PixelSprites/`. Runtime imports normalize transparent padding, snap alpha, and sample onto a 64 × 48 fish grid or 64 × 64 decoration grid (64 × 32 for hanging decorations). Nearest-neighbor rendering preserves edges. Grade colors and animated poses are derived by the native renderer; saved fish IDs, progression, and decoration order are unchanged.

## Shared generation prompt

Use case: stylized-concept. A single original aquarium game sprite. Strong chunky 16-bit PIXEL ART, cheerful game-like stylization inspired by PC FISH, NOT realistic illustration. Draw as if on a tiny 32x32 pixel grid enlarged 24x with nearest-neighbor: clearly visible large square pixels, stair-step contours, broad solid color clusters, only 6-8 colors, two flat shadow/highlight tones. Recognizable organic silhouette with gently exaggerated proportions. No tiny texture, no individual scales, no gradients, no soft edges, no glow, no painterly lighting, no fine detail, no 3D rendering, no text, no drop shadow. Genuine transparent background, whole subject centered filling most of a square canvas.
