# Synthetic test fixtures

These JSON files are generated test data, not exports of a player's aquarium.

- `web-save.json`: `tools/export-web-save-fixture.mjs` creates a new Web game at a fixed timestamp, adds catalog fish and explicit test settings, and exports it through the Web validator. It exercises legacy import, backup and migration behavior.
- `web-parity.json`: generated by `tools/generate-web-fixtures.mjs` for deterministic breeding and merging parity.
- `extras-parity.json`: generated by `tools/export-web-extras.mjs` for decorations and achievements.
- `reforge-parity.json`: `tools/export-web-reforge.mjs` exports 72 fixed-seed cases from the Web reforging rules, covering undiscovered secrets, partial/full collection and pity counters. It contains only synthetic progress and outcomes.

Never replace these files with a personal save or include actual acceptance snapshots here. Run generators against a separate checkout of the Web project.
